☕ T's Urban Brew
About the Project

T's Urban Brew is a modern coffee shop website designed to provide customers with an easy and enjoyable way to explore coffee products, view prices, place orders, and complete a simulated M-Pesa payment.

This project was developed as part of my web development and IT learning journey.

🚀 Features
🏠 Home page with coffee shop information
☕ Coffee and product menu
🛒 Shopping cart and checkout
📱 Simulated M-Pesa payment
👨‍💼 Admin dashboard
📱 Responsive and user-friendly design
⚡ Interactive features using JavaScript
🛠️ Technologies Used
HTML5 – Website structure
CSS3 – Styling and responsive design
JavaScript – Interactivity and functionality
